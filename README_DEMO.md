## 🎯 Тестовый сценарий

### Шаг 1: Установка
```bash
# Клонировать репозиторий
git clone https://github.com/yourusername/TehendSpeed_Parser.git
cd TehendSpeed_Parser

# Установить зависимости
pip install -r requirements.txt

# Настроить .env
cp .env.example .env
nano .env  # заполнить API_ID, API_HASH, BOT_TOKEN

# Запустить
python main.py
```

**Ожидаемый результат:**
```
INFO | Bot запущен: @YourBotName
INFO | Userbot запущен: @YourAccount  
INFO | База данных инициализирована: global_users.db
INFO | Парсинг-движок готов: 3 воркера
```

---

### Шаг 2: Многозадачный парсинг
1. Отправьте `/start` боту
2. Нажмите **"🔍 Запустить парсинг чатов"**
3. Отправьте 2-3 чата:
   ```
   @test_channel_1
   @test_channel_2
   https://t.me/+privateInviteHash
   ```
4. Наблюдайте параллельное обновление статусов

**Ожидаемое поведение:**
- ✅ Каждый чат обрабатывается отдельным сообщением
- ✅ Статусы обновляются каждые 3 секунды
- ✅ Счётчики растут независимо
- ✅ FloodWait обрабатывается автоматически

---

### Шаг 3: Дедупликация
1. Спарсите 2 чата с общими участниками
2. Зайдите в **"🗄 База данных → 📊 Статистика"**
3. Проверьте: **Всего уникальных** < сумма участников

**Проверка в SQLite:**
```sql
SELECT COUNT(*) FROM users;  -- уникальные по ID
SELECT id, COUNT(*) FROM users GROUP BY id HAVING COUNT(*) > 1;  -- должно быть 0 дублей
```

---

### Шаг 4: Фильтрация и экспорт
1. **"⚙️ Настройки фильтров"** → включить **"Только с номером"**
2. Спарсите чат заново
3. **"🗄 База данных"** → скачайте **XLSX**

**Проверка XLSX:**
- ✅ Заголовок с тёмным фоном и белым текстом
- ✅ Автофильтр на первой строке
- ✅ Закреплённый заголовок (freeze panes)
- ✅ Автоподобранная ширина колонок
- ✅ Колонки: ID | Name | Username | Premium | Phone | Source | Updated

---

### Шаг 5: Аналитика
```bash
# Поиск пользователя
/search durov

# Пересечение чатов  
/overlap crypto_chat | nft_chat

# Якорные (в 3+ чатах)
/anchors 3

# Тёплая аудитория (с username, 2+ чата) → XLSX
/warm 2

# График роста
/growth crypto_chat

# Новые/ушедшие
/diff crypto_chat

# Сегментация с графиком
/segments
```

---

### Шаг 6: Автопарсинг (Watchlist)
```bash
# Добавить чат (каждые 24 часа)
/watch add @crypto_chat 24

# Список расписания
/watch list

# Удалить
/watch del @crypto_chat
```

**Ожидаемое:**
- ✅ Чат автоматически парсится каждые N часов
- ✅ Результат приходит в личку
- ✅ Работает в фоне (фоновый планировщик)

## 💡 Pro Tips

### Оптимизация производительности
```env
WORKERS_COUNT=3  # 3-5 для мощных серверов
WORKERS_COUNT=1  # 1-2 при FloodWait
```

### Избежание FloodWait
- Не парсите >10 больших чатов (10k+ участников) подряд
- Используйте паузы между запусками
- Уменьшите `WORKERS_COUNT`

### Работа с приватными чатами
1. Userbot-аккаунт должен состоять в чате
2. Для invite-ссылок: сначала join, потом парсинг
3. Боты не могут парсить — только userbot
