## 🚀 Возможности

### Парсинг и Сбор Данных
- ⚡️ **Многопоточный парсинг** — обработка нескольких чатов параллельно (до 3-х воркеров)
- 🔄 **Автоматическое управление FloodWait** — умные паузы и продолжение при лимитах Telegram
- 🎯 **Дедупликация по ID** — исключает дубли, можно парсить один чат многократно
- 📱 **Фильтр "только с номером телефона"** — отсекает пользователей без контактов
- 🌐 **Поддержка всех типов ссылок** — @username, t.me/+hash, числовые ID

### База Данных и Хранение
- 💾 **SQLite Data Warehouse** — глобальная база всех спарсенных пользователей
- 📊 **Membership tracking** — кто в каких чатах и когда был замечен
- 📈 **История снимков** — динамика роста чатов, отслеживание new/left
- 🔍 **Полнотекстовый поиск** — по ID, username, имени
- ⏰ **Автопарсинг по расписанию** — watchlist с настраиваемым интервалом

### Аналитика
- 🔗 **Пересечения чатов** — найти общих участников между двумя чатами
- ⚓ **Якорные пользователи** — кто состоит в 2+, 3+, 5+ ваших чатах одновременно
- 🔥 **Тёплая аудитория** — сегмент под outreach с фильтрами (username, premium, фото)
- 📈 **Динамика роста** — графики изменения численности чата по времени
- 🔄 **Diff new/left** — кто вступил и кто вышел с прошлого снимка
- 🧩 **Сегментация базы** — визуализация по username, Premium, с номером, с фото
- 🚨 **Кросс-алерты** — уведомления о пользователях из других ваших чатов

### Экспорт
- 📥 **XLSX** — красивый Excel с автоподбором ширины и стилями
- 📥 **CSV** — универсальный формат для любых инструментов
- 📥 **JSON** — для разработчиков и интеграций
- 📥 **TXT** — простой текстовый список

### Визуализация
- 📊 **Графики роста** — matplotlib с темной темой
- 🥧 **Pie charts сегментов** — наглядное распределение аудитории
- 🎨 **Темная тема** — стильные графики в духе современных дашбордов

## 📦 Установка

### Требования
- Python 3.10 или выше
- Telegram Bot Token ([@BotFather](https://t.me/BotFather))
- Telegram API credentials ([my.telegram.org](https://my.telegram.org))
- Pyrogram session (для userbot-парсинга)

### Шаг 1: Клонировать репозиторий
```bash
git clone https://github.com/yourusername/TehendSpeed_Parser.git
cd TehendSpeed_Parser
```

### Шаг 2: Установить зависимости
```bash
pip install -r requirements.txt
```

### Шаг 3: Настроить .env файл
Создайте файл `.env` в корне проекта:

```env
# Telegram API (получить на my.telegram.org)
API_ID=12345678
API_HASH=your_api_hash_here

# Bot Token (получить у @BotFather)
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

# Pyrogram Session
USER_SESSION_STRING=your_session_string_here
USER_SESSION_NAME=userbot_parser

# База данных
DB_PATH=global_users.db

# Производительность
WORKERS_COUNT=3

# Приветственное медиа (опционально)
WELCOME_FILE=max.jpg
WELCOME_GIF=https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif

# Ограничение доступа (опционально, оставьте пустым для открытого доступа)
ADMIN_IDS=123456789,987654321
```

### Шаг 4: Получить Session String

#### Вариант 1: Через скрипт
```python
from pyrogram import Client

api_id = 12345678
api_hash = "your_api_hash"

async def main():
    async with Client("my_account", api_id, api_hash) as app:
        print(await app.export_session_string())

import asyncio
asyncio.run(main())
```

#### Вариант 2: Через Telegram Bot
Используйте [@StringSessionBot](https://t.me/StringSessionBot)

### Шаг 5: Добавить приветственное изображение (опционально)
Положите файл `max.jpg` в корень проекта для кастомного приветствия.

### Шаг 6: Запуск
```bash
python main.py
```

## 💡 Использование

### Быстрый старт
1. Отправьте `/start` боту в личные сообщения
2. Нажмите **"🔍 Запустить парсинг чатов"**
3. Отправьте ссылки на чаты (каждый с новой строки):
   ```
   @channel1
   https://t.me/+InviteHashHere
   -1001234567890
   ```
4. Дождитесь завершения — бот покажет прогресс в реальном времени
5. Экспортируйте результаты в нужном формате

### Примеры команд

#### Поиск пользователя
```
/search durov
/search 123456789
/search @username
```

#### Пересечение чатов
```
/overlap channel1 | channel2
```

#### Якорные пользователи (в 3+ чатах)
```
/anchors 3
```

#### Тёплая аудитория (с username, в 2+ чатах)
```
/warm 2
```

#### Динамика роста чата
```
/growth @channel_name
```

#### Новые/ушедшие участники
```
/diff @channel_name
```

#### Сегментация базы
```
/segments
```

#### Автопарсинг по расписанию
```
/watch add @channel 24
/watch list
/watch del @channel
```

## 🎨 Особенности

### Умное управление FloodWait
Бот автоматически обрабатывает лимиты Telegram:
- Ждёт указанное время
- Продолжает парсинг с места остановки
- До 2 попыток резюма на чат
- Дедупликация гарантирует отсутствие дублей

### Дашборд в реальном времени
```
📊 Парсинг — ✅142/150 • 🔄3 • ⏳5 • ❌0
████████████░ 95%
💾 В базе: 4521 (+1850 за запуск)

🔄 Сейчас обрабатываются:
• channel_crypto — 1200/1500 • 42.3/с • ⏱02:15
• channel_trading — 850/1000 • 38.7/с • ⏱01:45

⏳ В очереди (5): channel_news, channel_tech...
```

## 🔒 Безопасность

- ✅ Приватные данные (tokens, API keys) в `.env` — не коммитятся в git
- ✅ Опциональное ограничение доступа через `ADMIN_IDS`
- ✅ Userbot работает от вашего Telegram-аккаунта (нужны права)
- ✅ Все данные хранятся локально в SQLite

### Важно
- Userbot должен состоять в чатах, которые вы парсите
- Приватные чаты требуют членства
- Соблюдайте правила Telegram по использованию API
- Не злоупотребляйте парсингом (риск бана)

## 🆘 FAQ

<details>
<summary><b>Как получить API_ID и API_HASH?</b></summary>

1. Перейдите на [my.telegram.org](https://my.telegram.org)
2. Войдите с вашим номером телефона
3. Перейдите в "API development tools"
4. Создайте приложение и скопируйте `api_id` и `api_hash`
</details>

<details>
<summary><b>Userbot не видит участников чата</b></summary>

Убедитесь, что аккаунт, от которого создан session string:
- Состоит в этом чате (для приватных)
- Не забанен в чате
- Имеет права на просмотр участников
</details>

<details>
<summary><b>FloodWait не проходит / бот падает</b></summary>

- Telegram ограничивает скорость запросов
- Бот автоматически ждёт и продолжает (до 2 попыток)
- Если лимиты жёсткие — уменьшите `WORKERS_COUNT` до 1-2
- Попробуйте парсить позже
</details>

<details>
<summary><b>Можно ли парсить без userbot?</b></summary>

Нет, Bot API не даёт доступа к списку участников. Требуется MTProto (Pyrogram userbot).
</details>

<details>
<summary><b>База данных растёт — как почистить?</b></summary>

```bash
rm global_users.db
```
При следующем запуске создастся новая пустая база.
</details>
